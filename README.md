# quiz-app

一問一答式のクイズWebアプリです。

## このアプリでできること
- 問題と答えを自分で入力して追加できる
- 1問1答形式で遊べる
- 「勉強する」「テストする」で問題番号を指定して途中から始められる
- 問題ごとの定着度に応じて、今日復習する問題を出題できる
- 小学1年生でも見やすい、可愛くポップなUI
- ブラウザを閉じても問題が保存される
- ペット「ソラ」の育成、アイテムの購入・使用、健康管理

## 使い方
1. `index.html` をブラウザで開く
2. 「問題」と「答え」を入力して「追加する」を押す
3. クイズ画面で自分の答えを入力して「こたえる」を押す
4. 正解するとポイントが増えます
5. 「つぎへ」で次の問題に進む

「勉強する」「テストする」では、カテゴリなどで問題を絞り込んだあと「開始番号」を指定すると、その番号の問題から始められます。

「テストする」画面の「今日のクイズ」を押すと、今日復習する問題だけが出題されます。定着度は初期値1で、正解すると最大6まで1上がり、誤答すると1に戻ります。定着度2〜6の問題は、最後に正解してからそれぞれ1・3・7・14・30日以上経つと復習対象になります。

ホーム画面右下の「Pet」からソラのお世話ができます。コインは最初に10枚あり、クイズに正解すると1枚もらえます。新しいペットの初期ステータスは、あたま・たいりょく・こころが各5、おなか・えいよう・げんきが各50、なつきが10です。ショップには、おにぎり・やさい・おにく・さかな・おかしのほか、ざっそう・どんぐり・しおむすび・サラダスティック・ステーキ・ドーナッツ・えんぴつ・なわとび・おもちゃがあります。「逃がす」を選ぶと確認のあと、コイン・もちもの・ステータスを初期状態に戻せます。

## ローカルで動かす方法
```bash
cd /workspaces/quiz-app
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開いてください。
