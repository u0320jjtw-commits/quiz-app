# quiz-app

一問一答式のクイズWebアプリです。

## このアプリでできること
- 問題と答えを自分で入力して追加できる
- 1問1答形式で遊べる
- 小学1年生でも見やすい、可愛くポップなUI
- ブラウザを閉じても問題が保存される

## 使い方
1. `index.html` をブラウザで開く
2. 「問題」と「答え」を入力して「追加する」を押す
3. クイズ画面で自分の答えを入力して「こたえる」を押す
4. 正解するとポイントが増えます
5. 「つぎへ」で次の問題に進む

## ローカルで動かす方法
```bash
cd /workspaces/quiz-app
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開いてください。
